# Novaristan – Serious Game

Pack prêt pour GitHub Pages.

## Contenu
- `index.html` : application principale
- `.nojekyll` : désactive le traitement Jekyll automatique
- `404.html` : page d’erreur simple

## Mise en ligne rapide
1. Créez un dépôt GitHub.
2. Déposez tout le contenu de ce dossier à la racine du dépôt.
3. Dans **Settings > Pages** :
   - **Source** : `Deploy from a branch`
   - **Branch** : `main`
   - **Folder** : `/ (root)`
4. Enregistrez.
5. Après publication, l’application sera disponible à l’adresse GitHub Pages du dépôt.

## Utilisation locale
Ouvrir simplement `index.html` dans un navigateur moderne.

## Remarque
L’application utilise le stockage local du navigateur pour certaines préférences et sauvegardes locales.
